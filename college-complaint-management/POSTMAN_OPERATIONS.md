# Postman Operations

Base URL: `http://localhost:8080`. Register with `POST /students/register`, login with `POST /students/login`, and send the returned token as `Authorization: Bearer <token>`.

Core requests: `GET /students`, `GET /students/1`, `PUT /students/1`, `DELETE /students/1`, `POST /departments`, `GET /departments`.

Complaint requests: `POST /complaints`, `GET /complaints`, `GET /complaints/student/1`, `PUT /complaints/1/status`, `POST /complaints/1/responses`.
